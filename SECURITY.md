# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use the
repository's private security advisory flow or contact the maintainers
directly with a reproducible description, affected versions, and a proposed
mitigation if available.

Mory is local-first, but its API can expose personal memories to local
processes. Do not bind the service to a public interface unless you have
added authentication, TLS, and an explicit network access policy.

## Supported versions

Security fixes target the latest released version and the default branch.
